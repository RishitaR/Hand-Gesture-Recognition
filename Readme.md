# Hand Gesture Recognition

A robust computer vision and deep learning-based system designed to recognize and predict 37 Indian Sign Language gestures. The project leverages the power of the VGG16 model to achieve high accuracy and real-time performance.

## Features

- **Gesture Prediction**: Predicts 37 Indian Sign Language gestures with 95% accuracy.
- **Real-Time Recognition**: Optimized for speed and performance to enable real-time gesture recognition.
- **Deep Learning Model**: Evaluated multiple deep learning models and selected VGG16 for its superior accuracy.
- **Extensible**: Framework designed to be easily extended to include more gestures or adapt to other sign languages.

## Technologies Used

- **Python**: Core programming language for development.
- **VGG16**: Pre-trained deep learning model for feature extraction and classification.
- **PyCharm**: Integrated Development Environment (IDE) for efficient coding and debugging.
- **OpenCV**: For real-time video capture and preprocessing (if applicable).
- **NumPy**: For efficient numerical computations.
- **TensorFlow/Keras**: For training, fine-tuning, and deploying the VGG16 model.

## Dataset

The dataset consists of 37 Indian Sign Language gestures, with each gesture represented by multiple samples. Each image is preprocessed and resized to match the input dimensions required by the VGG16 model (224x224 pixels).

## Results

Results
Model Accuracy: 95%
Real-Time Performance: Recognizes gestures with minimal latency.
Evaluation: Multiple models were evaluated, with VGG16 delivering the best balance of accuracy and performance.
